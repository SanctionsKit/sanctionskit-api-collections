# Security

Report credentials exposed in this repository or other sensitive issues to **support@sanctionskit.com**. Do not include active secrets or customer data in a public issue.

If you accidentally share an API key, revoke it in [API keys](https://www.sanctionskit.com/dashboard/keys?environment=sandbox) and create a replacement. Deleting the file alone does not remove the key from Git history.

Read about service controls on the [SanctionsKit security page](https://www.sanctionskit.com/security).
